# The Explorers 1.0.0

Release date: 15 November 2026. Intended use: local team demonstration and research planning.

## Included

- Arcadia and Jezero measured terrain planning, unified Arcadia/AR source catalog, and unrestricted map exploration with a 100 × 100 km regional coverage outline.
- Explicit Get directions action, shortest and minimum-peak-slope alternatives, editable From/Destination, and clear coverage/feasibility errors.
- Worker-based route analysis and terrain preprocessing, cached meshes, interactive Arcadia WebGL terrain, and local frontend dependencies.
- Science stop ordering, mission constraints, archived climate context, database save/restore, briefing export, and print view.
- Dark/light themes, responsive navigation, built-in guide, keyboard focus indicators, reduced motion, and direct password-free access.
- HTTPS gateway, public datasets/API, cross-origin mutation protection, and loopback-only backend.
- Fresh-host setup launcher and source/data archive containing all original AR source files. Private keys, installed dependencies, and live database records are excluded.

## Validation

TypeScript checking and frontend build passed. `npm run verify` passed: 32 backend tests plus actual compiled terrain-worker checks, safety logic, live frontend/API integration, directions forms, manual route-trigger behavior, science mission save/restore, and verified HTTPS and direct access.

Measured worker smoke-test timings on this host: initial preload 413 ms, regional route 29 ms, cached speed change 1 ms, mesh generation 38 ms. These are test observations, not guarantees for every device or route.

Browser visual inspection could not be completed because the browser automation host was unavailable and native Chrome reported unavailable input geometry. DOM integration and API tests passed; a final human visual review on target PCs is recommended.

Wrangler and Zod were updated, and validation error handling migrated to Zod 4. npm audit reports zero high/critical findings and four moderate findings in the drizzle-kit schema-generation dependency chain. This tool is not an API endpoint; advisories remain and should be revisited before a public deployment.

## Operational limits

This release uses a local Workers development runtime behind the TLS gateway. It is not an Internet production hosting configuration or certified astronaut navigation system. Clients must explicitly trust the supplied local CA for their host. Access is open to anyone who can reach the host; saved plans are shared and editable by all visitors. Back up the local database before updates. No public deployment or challenge submission was performed.

Slope-based alternatives do not model all hazards, spacesuit life support, dust events, or live radiation/weather. Source coverage, archived model times, missing elevations, and AR metadata damage remain visible. External global tiles need Internet; local grids and imagery are included.

## Development acknowledgment

The team used OpenAI Codex to assist with implementation, debugging, integration, documentation, and verification. Scientific source measurements were not generated by an AI model. The 3D surface is a triangle mesh derived from elevation data, rendered with Three.js, rather than a generative or trained AI model.
